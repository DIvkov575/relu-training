How this was made

This is a newly trained flow model, separate from the ReLU height models. During training, it sees a random Gaussian point, a random point inside MIG, and a random time between them. It learns the required movement from these examples. During playback, new Gaussian points move using only that learned movement; they are not assigned destinations in the letters.

Network: 3 hidden layers of 96 units, with tanh activation, taking a point, position features and time features and returning its two movement components. Trained for 40,000 steps with batches of 512. The animation follows 32,768 new points with 240 midpoint integration steps.

Each image counts points in a 180 × 180 grid. A small 1.1-cell blur makes the finite point sample readable. Brightness uses a fixed logarithmic density scale; it is not renormalized each frame. Between computed times, the display blends adjacent density frames. The optional arrows show the network’s predicted motion. The view covers −3.6 to 3.6 on both axes; about 5% of the starting Gaussian lies outside this view.
